Track left/right points, matching, carry-forward and cheque earnings as your branches grow.

Branch rulesShow rules
Each node has at most one left child and one right child. Clicking a side's + follows that same-side branch to its deepest node and adds the next child there. Every input starts at 10. The primary node is labelled Owner; added nodes are named S1, S2, S3… in creation order and show the name of the node whose + button was clicked (for example, S1 (by Owner), S2 (by Owner), S3 (by S2)). Owner uses dark slate; every node in the Owner's left organisation uses teal; every node in the right organisation uses violet. Descendants keep their organisation's colour regardless of which node adds them. Both + buttons match their node's border colour. The left and right organisations remain in separate zones divided by a vertical centre line. Owner’s initial 10 points are excluded from side totals. Every 3 points on each side create 1 cheque worth $252 (3 × $42 × 2 sides); unmatched points carry forward.
Use either + button to add the first child
